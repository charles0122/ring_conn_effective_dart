# 团队规范概览

`团队规范` 是项目内 Dart 代码规范的权威版本。这里记录的是团队已经决定采纳、并且愿意长期维护的规则。

`官方参考` 分组仅用于查阅 Effective Dart 原始建议，不代表团队已经全部采纳。是否执行，请始终以本分组为准。

## 维护原则

- 团队规范优先服务于当前代码库的可读性、一致性和 review 成本，而不是完整复刻官方原文。
- 新增规则时，至少写清楚 3 个字段：规则标题、规则级别、采纳理由。
- 如果规则来源于 Effective Dart，优先附上官方来源链接；如果存在可落地的 lint，也建议补上。
- 当团队规范与官方建议不一致时，以团队规范为准。
- 对设计交付、开发协作这类非 Dart 语言规则，也可以进入团队规范，但需要写清楚适用角色和执行方式。

## 条目模板

每条规则建议采用统一格式：

1. 规则标题
2. 级别 badge
3. 规则描述
4. 采纳理由
5. 可选的官方来源
6. 可选的相关 lints
