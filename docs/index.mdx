# RingConn Dart 代码规范

这里用于沉淀我们团队自己维护的 Dart 代码规范。

文档分成两层：

- [团队规范](/team-guidelines)：团队当前采纳并要求执行的规则，是唯一权威版本
- [官方参考](/effective-dart)：同步自 Effective Dart 的中文内容，仅用于查阅和对照

这意味着：

- 官方 `DO / DON'T / PREFER / AVOID / CONSIDER` 不自动等于团队已经采纳
- 团队会结合现有工程、review 成本和可落地性，决定哪些规则进入采纳清单
- 后续新增或调整规则时，以团队规范分组中的内容为准

## 预览方式

本仓库使用 `docs.page` 官方的本地预览模式。

1. 打开 [docs.page/preview](https://docs.page/preview)
2. 选择当前仓库根目录
3. 保存 `docs/` 或 `docs.json` 中的修改
4. 在浏览器中实时查看效果

## 维护方式

- 团队规范页面由团队手工维护，不会被同步脚本覆盖
- 官方参考页面来自 Dart 中文社区维护的 Effective Dart 中文文档
- 团队是否采纳某条官方建议，以团队规范页面里的规则条目为准

当前官方参考来源：
[cfug/dart.cn/effective-dart](https://github.com/cfug/dart.cn/tree/main/src/content/effective-dart)

同步时会做轻量清洗，用于适配 `docs.page` 渲染。
